# Curated — Android (Jetpack Compose)

Pakistani fashion e-commerce + AI Personal Stylist app. Pixel-close to the rose/glass mockups in `curate-main`.

## Stack
- Kotlin + Jetpack Compose + Material3 (custom theme)
- Navigation Compose, Hilt, Coil, DataStore
- Offline mock catalog (PKR / Pakistani brands)

## Open & run
1. Install [Android Studio](https://developer.android.com/studio) (Ladybug+ recommended).
2. **File → Open** this folder (`Curate Android`).
3. Let Gradle sync; install SDK 35 if prompted.
4. Run the `app` configuration on an emulator or device (API 26+).

## App flow (MVP)
Splash → Home (bottom nav) → AI Stylist → Your Curated Look → PDP → Cart → Checkout stub  
Also: Wishlist, My Outfits, Profile.

## Brand assets
Logo cutout and pink brand field are copied into `app/src/main/res/drawable/`.
Product imagery uses placeholder gradients until licensed photos are provided.
